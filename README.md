# VVeChat OS 1.0.0

A clean rewrite of VVeChat. Single-server architecture:
- Backend: Express + Socket.io + better-sqlite3 + JWT
- Frontend: vanilla HTML/CSS/JS (no build step)

## Deploy
- Root Directory: empty (we serve frontend from Express)
- Build: `npm install`
- Start: `npm start`
- Node: 18.x
